# Tracker

## Описание

Tracker — это iOS-приложение, которое помогает пользователю формировать полезные привычки и отслеживать их выполнение.

Приложение позволяет пользователю создавать карточки-трекеры привычек, задавать для них расписание, отслеживать выполнение по дням и анализировать прогресс с помощью статистики.

Проект разработан в учебных целях для практики работы с:
- локальным хранением данных с помощью CoreData
- версткой коллекций с помощью UICollectionView
- реализацией пользовательских сценариев: созданием, редактированием и удалением данных в приложении
- календарем, фильтрацией и поиском
- локализацией

## Технологии

- Swift
- UIKit
- Архитектура MVC / MVVM (для отдельных экранов)
- UICollectionView
- CoreData
- NSFetchedResultsController
- Auto Layout

## Требования

- Xcode 15+
- iOS 17+
- Swift 5+

1. Клонировать репозиторий: `git clone https://github.com/BeerHobbit/Tracker.git`
2. Открыть проект в Xcode
4. Запустить проект на эмуляторе или подключенном устройстве
